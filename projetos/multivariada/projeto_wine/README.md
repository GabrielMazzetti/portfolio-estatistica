# Análise Multivariada — Conjunto de Dados Wine (UCI)

Análise de 178 amostras de vinhos italianos de três cultivares a partir de 13 variáveis químicas, aplicando Análise de Componentes Principais (PCA via decomposição espectral manual), Análise Fatorial por máxima verossimilhança e Análise Discriminante (LDA e QDA) sob a ótica de controle de qualidade e certificação de lotes desconhecidos.

## Arquivos

- `wine.html` — Relatório interativo renderizado em Quarto (inclui projeção 3D em Plotly)
- `case_wine.html` — Estudo de caso executivo do projeto
- `wine.qmd` — Código-fonte reprodutível em R / Quarto
- `analise_wine.pdf` — Versão em PDF do relatório
- `wine.dat` — Base de dados original (UCI Machine Learning Repository)
- `referencias.bib` — Referências bibliográficas
