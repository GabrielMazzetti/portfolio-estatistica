# Portfólio de Estatística — Gabriel Mazzetti

Portfólio pessoal de **Gabriel Sanábio Mazzetti Affonso**, graduando em Estatística pela Universidade Federal de Juiz de Fora (UFJF), reunindo projetos em inferência estatística, modelagem, análise multivariada, aplicações interativas em R Shiny e materiais técnicos em Python e Quarto.

## Estrutura do repositório

| Pasta / arquivo | Conteúdo |
| --- | --- |
| `index.html` | Página inicial (apresentação, projetos em destaque, sobre mim, formação e experiência, competências e contato) |
| `projetos.html` | Listagem completa dos projetos acadêmicos e técnicos |
| `projetos-pessoais.html` | Projetos pessoais independentes publicados na web (ex.: KinoMap) |
| `sites.html` | Redirecionamento automático para `projetos-pessoais.html` |
| `style.css` | Folha de estilos unificada do portfólio e dos estudos de caso |
| `assets/` | Foto de perfil e capturas reais das aplicações, gráficos e materiais (`assets/projetos/`) |
| `projetos/computacional/sumarios_embrapa.html` | Estudo de caso unificado das aplicações R Shiny dos Sumários de Touros 2026 (Gir Leiteiro e Girolando — Embrapa) |
| `projetos/computacional/livro_python.html` | Estudo de caso do livro digital *Python, Web Scraping e Livros Digitais* (IC — UFJF) |
| `projetos/multivariada/projeto_wine/` | Relatório em Quarto, PDF, dados e estudo de caso de análise multivariada do conjunto Wine (UCI) |
| `projetos/estatistica-descritiva/projeto_employee_attrition/` | Relatório exploratório de Employee Attrition em R e Quarto |
